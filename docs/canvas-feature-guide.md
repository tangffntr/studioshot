# 画布功能使用指南

## 概述

画布功能为用户提供了一个可视化的图片编辑工作区，可以将资产库中的图片添加到画布中进行精修和重新生成。

## 功能特性

### 1. 资产选择
- 左侧面板显示资产库中的所有图片
- 支持搜索筛选（按提示词或slotCode）
- 点击图片即可添加到画布

### 2. 画布操作
- **自由拖拽**：拖拽图片调整位置
- **画布缩放**：使用鼠标滚轮缩放画布
- **画布移动**：拖拽画布空白区域移动视图
- **选中图片**：单击图片选中，显示蓝色边框
- **放大图片**：双击图片放大查看

### 3. 提示词编辑
- 选中图片后，底部显示提示词编辑面板
- 点击"编辑"按钮修改提示词
- 点击"保存"按钮保存修改
- 点击"重新生成"按钮生成新图片

### 4. 快捷键
- `Delete` / `Backspace`：删除选中的图片
- `Escape`：取消选中/关闭编辑

## 使用流程

### 步骤1：进入画布
1. 点击左侧菜单栏的"画布"选项
2. 进入画布视图

### 步骤2：添加图片
1. 在左侧面板浏览资产库
2. 使用搜索框筛选图片
3. 点击图片添加到画布

### 步骤3：编辑图片
1. 在画布中单击选中图片
2. 底部显示提示词编辑面板
3. 点击"编辑"修改提示词
4. 点击"保存"保存修改
5. 双击图片可放大查看

### 步骤4：重新生成
1. 选中要重新生成的图片
2. 修改提示词（可选）
3. 点击"重新生成"按钮
4. 等待生成完成，新图片自动添加到画布

## 界面说明

### 左侧资产面板
- **搜索框**：筛选资产
- **资产网格**：显示资产库图片
- **slotCode标签**：显示图片的slot代码

### 中间画布区域
- **工具栏**：显示缩放比例和操作按钮
- **画布**：可拖拽、缩放的工作区
- **图片卡片**：可拖拽的图片，显示提示词预览

### 底部提示词面板
- **提示词内容**：显示当前选中图片的提示词
- **操作按钮**：编辑、保存、重新生成

## 技术实现

### 状态管理
- `canvasItems`：画布项目列表
- `selectedCanvasItemId`：当前选中的项目ID

### API调用
- `GET /api/media`：获取资产列表
- `PATCH /api/media/:id`：更新提示词
- `POST /api/jobs`：提交重新生成任务

### 样式文件
- `canvas.css`：画布相关样式

## 注意事项

1. **图片大小**：画布中的图片默认200x200像素
2. **缩放范围**：支持0.1x到3x缩放
3. **生成时间**：重新生成可能需要几秒到几十秒
4. **自动刷新**：资产列表每10秒自动刷新
5. **状态保存**：画布状态在页面刷新后会重置

## 故障排除

### 图片无法添加
- 检查网络连接
- 确认资产库中有图片
- 刷新页面重试

### 重新生成失败
- 检查提示词是否有效
- 确认后端服务正常运行
- 查看控制台错误信息

### 画布操作无响应
- 确保画布区域获得焦点（点击画布区域）
- 检查是否有JavaScript错误
- 刷新页面重试
